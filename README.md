# 歧路花开 · Qilu Huakai

一款 18–35 岁的人生决策演练场：先掷命，再给一次改写机会，高考报名开始演练，NPC 各有性格，承诺与兑现错开 1–3 年。**人生不止一条路，把不敢做的选择，先在这里演练一遍。**

- 比赛：支付宝智能体涌现奖 2026（生活好帮手赛道），提交截止 **2026-12-06 零点**
- 实现：纯前端代码版（HTML/CSS/JS，无构建、无后端、无登录、本地存档）
- 设计稿 v5：见 `~/workspace/hackathon-tracker/alipay-emerge-rpg-design-20261116.md`（本仓库只放代码与玩法说明）

## 玩法

- **开局（S0–S6）：** 选执念（1–2 条）与难度（免费，开局锁死）→ 掷骰 → 出身卡（一屏 5 行，标题“你没得选的那部分”）→ 成长片段 → 转场三屏（账单 / 入账 / 签字）→ T1 高考报名，签承诺卡 A。
- **第一周目没有改写入口（v5）。** S4 改写（「照我的来」文本 → 标签回显 → 重掷 → 对照）只在结算后「再来一次」时解锁；周目位免费 1 位，2–3 号位付费解锁（演示版未接入支付，不会真的收费）。
- **年度循环：** 每年 3 个行动点（AP），18 回合。承诺签署时掷骰并封存，只给 1–3 条征兆（准确率 65%），T+1 到 T+3 年兑现。兑现卡会告诉你“真正能救你的是什么”和“你当时忽略了什么信号”。
- **压力三档 + Debt：** 稳 / 紧绷 / 崩；紧绷以上每年 Debt +1，上限 5；Debt 到顶触发躯体化事件。
- **3 分钟切片：** 标题页点「3 分钟切片：直接进 26 岁」，直接进 T9 裁员之夜——HR 已约明早谈话、尚未送达正式解除通知；今晚决定三件事（找谁聊聊、明早 HR 谈话怎么谈、按存款缺口借不借钱）。裁员与否的骰子（H2）在进切片那一刻已封存，三个决定只定应对、不定结果；补偿按工龄算 N，代通知金不是所有裁员都有。

## 公平性规则（写进代码的）

- 骰子在签署那一刻掷出并写进存档；兑现只读档，**绝不重掷**。种子与 RNG 流位置一起存档，刷新页面也改不了任何一个未来的掷骰结果。
- 每次正式行动后自动保存；存档码（`QILU1-` 开头）可导出 / 导入，种子与封存骰都在码里。
- 演练不暴露封存骰、不决定正式存档结果。

## 本版范围（v0.3，专属线 AI 审核）

点子确认页多了两样东西：

- **补充说明（可选）：** 玩家可以写一句为什么这个点子合理、能赚钱（比如“身边真有人为改简历付费”）。
- **请 AI 审核（可选）：** 点了才把点子和补充说明发给一个免费 AI 接口（Pollinations，免登录、免密钥、免付费），由它给最终结果：点子成不成立、分到哪一类、启动成本定多少。关键词分类只是第一版判断，AI 说了算。

规则：AI 说成立，按 AI 的分类和定价开线（实测里 AI 把一个 AI 求职助手的启动费从关键词的 2 万调到了 3 万）；AI 说不成立，直接开线关闭，只能改想法、或先做免费验证；AI 连不上（接口偶尔会断一次，重试一次还不行就认），就按关键词分类开线，并明确告诉玩家。游戏离线照样能玩。

测试：`tests` 不在仓库里，见 `~/workspace/hackathon-tracker/qilu-huakai-tests/test-v03.js`（34 项全过，含 AI 通过 / 不通过 / 断网三条路）与 `test-v02-regression.js`（v0.2 回归 8 项全过）。

## 本版范围（v0.3.1，T1 专业自由输入）

修了一个真缺口：T1 高考志愿填报之前从没让玩家说过自己想报什么专业——三个立场按钮（听父母的 / 坚持自己 / 谈判）只定系数 k，不定专业。游戏里唯一出现过“会计”两个字的地方，是 S3 成长片段里的一句征兆台词（“你妈说隔壁家孩子学了会计”），那根本不是选项。

现在 T1 先问“你想报的专业”：一个输入框（想写什么写什么）加 10 个常用专业点一点就填进去（计算机、临床医学、法学、金融、会计、新闻传播、土木、英语、艺术设计、师范）。然后三个立场才有意义：坚持自己就报你写的专业（k = 1.3）；听父母的就报省内师范（k = 1.0）；谈判折中还是报你写的专业，但 k = 1.0。专业写进存档（`s.major`）和承诺卡 A，T5 回顾时会再点一次名。直接进 26 岁切片的默认开局按“听父母的”算，专业是省内师范。

测试：`~/workspace/hackathon-tracker/qilu-huakai-tests/test-v04.js` 18 项全过；v03 与 v02 回归套件重跑全过。

## 本版范围（v0.4，高考分数 + 看广告提分 + 山东政策）

先做一个地区：山东（游戏就叫齐鲁）。政策是核实过的真数：2026 山东夏季高考普通类特殊类型线 525、一段线 442、二段线 150（省招考院 2026-06-25 发布）；3+3 模式，总分 750；普通类分提前批+常规批，2026 年起取消特殊类型批；常规批 3 次填报，每次最多 96 个“专业+学校”平行志愿；一段线按本科计划 1:1.2 划定。

玩法：进 T1 先出分——高考总分是封存骰，420–660 之间掷一次，之后不再重掷。分数卡上同时显示一段线、特殊类型线和二段线。看广告提分：每次 +10 分，本局最多 3 次（+30 封顶）；演示版是 5 秒模拟播放，未接真实广告 SDK，接广告时换这里。每个专业有一条游戏参考线（一段线 + 偏移，如临床医学 +160、计算机 +140、会计 +90、艺术设计 +0），输入专业后实时显示达线还是差几分，未列出的专业默认 +60。录取结果由分数定：达线正常录取（k 按立场）；过了一段线但差分 → 调剂到分数够得着的最高专业，k = 1.0；没过一段线 → 专科批次，k = 0.8（设计稿里 0.8 那档终于有了归属）。专业和批次（本科 / 本科（调剂） / 专科）写进承诺卡 A，T5 回顾时再点一次名。

逐省扩大的口子留好了：`GAOKAO_REGIONS` 里加一个省就是一条数据，`GAOKAO_DEFAULT_REGION` 换默认地区；参考线表 `MAJOR_LINE_OFFSETS` 也按省分开记（现在只有山东一版）。

测试：`~/workspace/hackathon-tracker/qilu-huakai-tests/test-v05.js` 28 项全过（含真实 5 秒广告计时）；v04/v03/v02 回归套件重跑全过。
