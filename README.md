# 歧路花开 · Qilu Huakai

一款 18–35 岁的人生决策演练场：先掷命，再给一次改写机会，高考报名开始演练，NPC 各有性格，承诺与兑现错开 1–3 年。**人生不止一条路，把不敢做的选择，先在这里演练一遍。**

- 比赛：支付宝智能体涌现奖 2026（生活好帮手赛道），提交截止 **2026-12-06 零点**
- 实现：纯前端代码版（HTML/CSS/JS，无构建、无后端、无登录、本地存档）
- 设计稿 v5：见 `~/workspace/hackathon-tracker/alipay-emerge-rpg-design-20261116.md`（本仓库只放代码与玩法说明）

## 玩法

- **开局（S0–S6）：** 选执念（1–2 条）与难度（免费，开局锁死）→ 掷骰 → 出身卡（一屏 5 行，标题“你没得选的那部分”）→ 成长片段 → 转场三屏（账单 / 入账 / 签字）→ T1 高考报名，签承诺卡 A。
- **第一周目没有改写入口（v5）。** S4 改写（「照我的来」文本 → 标签回显 → 重掷 → 对照）只在结算后「再来一次」时解锁；周目位免费 1 位，2–3 号位付费解锁（演示版未接入支付，不会真的收费）。
- **年度循环：** 每年 3 个行动点（AP），18 回合。承诺签署时掷骰并封存，只给 1–3 条征兆（准确率 65%），T+1 到 T+3 年兑现。兑现卡会告诉你“真正能救你的是什么”和“你当时忽略了什么信号”。
- **压力三档 + Debt：** 稳 / 紧绷 / 崩；紧绷以上每年 Debt +1，上限 5；Debt 到顶触发躯体化事件。
- **3 分钟切片：** 标题页点「3 分钟切片：直接进 26 岁」，直接进 T9 裁员之夜——HR 已约明早谈话、尚未送达正式解除通知；今晚决定三件事（找谁聊聊、明早 HR 谈话怎么谈、按存款缺口借不借钱）。裁员与否的骰子（H2）在进切片那一刻已封存，三个决定只定应对、不定结果；补偿按工龄算 N，代通知金不是所有裁员都有。

## 公平性规则（写进代码的）

- 骰子在签署那一刻掷出并写进存档；兑现只读档，**绝不重掷**。种子与 RNG 流位置一起存档，刷新页面也改不了任何一个未来的掷骰结果。
- 每次正式行动后自动保存；存档码（`QILU1-` 开头）可导出 / 导入，种子与封存骰都在码里。
- 演练不暴露封存骰、不决定正式存档结果。

## 本版范围（v0.7.1，非创业点子守门：ev-idea 分类修正）

Allen 2026-11-17 04:13 截图报的 bug：“和父母要钱买上海的房子”在确认屏上被识别为“创业项目（启动 2 万）”，还配了“做出最小版本 / 找到第一批用户 / 收支打平”的里程碑和“跑通后每年钱 +2 万”。根因：关键词分类零命中就兜底进通用创业线——兜底是给含糊但像生意的想法准备的，可这句没有卖的东西、没有付钱的客户、没有收费方式，根本不是创业点子。

修法：`engine.js` 新增 `nonVentureReason()`，在分类之前先守门——只有零创业关键词命中时才生效（“借钱开奶茶店”有奶茶关键词，照常进本地实体经营）。四类：向家里要钱买东西（ask-family）、攒钱买房买车（saving）、买房买车自用（purchase）、找工作/考公/考研（career）；“买房出租”带出租不拦（算含糊生意，仍走通用兜底），“做旅游攻略号”“开留学中介”也不拦。这类输入进确认屏不再是分法选择器，而是一张“这不是一条创业线”卡：说明为什么（家庭决策 / 花钱不是赚钱 / 职业选择），没有确认开始、没有免费验证——只有请 AI 审核（申诉口）、先记下来、返回改想法。AI 审核也补了一个新结论：`archetype: "none"`（只配 reasonable=false），表示“这根本不是创业点子”；AI 说能开（reasonable=true）就按它的分法回到正常确认屏。另修一个顺带发现的小 bug：确认/验证按钮读下拉框时，空值会悄悄把线换成列表第一项 AI 工具创业（v0.3 的测试没发现，因为它的 AI 结论正好就是 AI 工具）；现在空值回落到待确认点子自己的分法。
